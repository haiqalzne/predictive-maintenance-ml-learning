# Experiment record template

Copy this into your ignored local learning-run directory. Publish only a reviewed, sanitized
aggregate report; do not include personal paths, credentials or raw records.

- Date / experiment identifier:
- Question and prediction before running:
- Evidence type: source reading / assisted exercise / independent demonstration / retained skill.
- Code commit and upstream base:
- OS, Python and dependency versions:
- Data source, license, checksum and permitted features:
- Split/fold protocol, seed, grouping/order assumptions:
- Final-test access so far (including upstream published results):
- Baseline and primary/secondary metrics:
- One factor changed; everything intentionally held fixed:
- How model/threshold/calibration selection avoided the final test:
- Commands and output locations (portable paths only in public reports):
- Results, uncertainty and subgroup support:
- False-positive and false-negative examples, without sensitive records:
- Valid/invalid/failure tests and reproduction result:
- Interpretation, limitations and whether the original prediction held:
- What I can now explain or change:
- Revision references, human/AI assistance and generated material used:
- Unresolved questions and next experiment:

Do not fill in an expected metric as if it were observed. A negative or inconclusive result is
useful when the comparison is controlled and its limits are explicit.
